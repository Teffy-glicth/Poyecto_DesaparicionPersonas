Cómo abrir el informe
Opción 1: en línea

Entrar a https://poyecto-desaparicionpersonas-kefg.onrender.com/ y navegar con el menú de la página principal. Si el servicio estuvo inactivo, la primera carga puede tardar unos segundos.

Opción 2: de forma local
Clonar el repositorio y entrar a la carpeta:
bash
   git clone https://github.com/Teffy-glicth/Poyecto_DesaparicionPersonas.git
   cd Poyecto_DesaparicionPersonas
(Opcional) Crear y activar un entorno virtual:
bash
   python -m venv venv
   source venv/bin/activate      # En Windows: venv\Scripts\activate
Instalar las dependencias:
bash
   pip install -r requirements.txt
Iniciar la aplicación:
bash
   python app.py
Abrir en el navegador la dirección que indique la terminal (normalmente http://127.0.0.1:5000). En GitHub Codespaces, abrirla desde la pestaña Ports.
Opción 3: abrir el tablero de Power BI
Abrir powerbi/ConocimientoEvidente_Final.pbix con Power BI Desktop. El mismo tablero se muestra dentro del informe en la ruta /etapa4/tablero.
