2. Diseño del ETL en SSIS

El proceso se construyó en SQL Server Integration Services sobre una instancia SQL Server LocalDB. El paquete etl/ssis/ETL_Principal.dtsx contiene dos flujos de datos: ETL Iteracion 1 (línea base) y ETL Principal (reglas completas).

Base de datos

ObjetoFunción
staging.desaparecidos_rawCopia cruda del CSV, sin tipos ni validaciones. Es la zona de trazabilidad.
ref.tipo_evento_homologadoCatálogo para homologar tipo_evento (Lookup).
dbo.desaparecidos_finalRegistros aceptados, con tipos correctos y id_registro único.
revision.desaparecidos_pendientesRegistros que requieren revisión, con valor original y motivo.
control.control_cargasUna fila por ejecución con recibidos, aceptados, duplicados y revisión.

Control Flow

  1. Iniciar carga (Execute SQL Task): inserta la ejecución en control.control_cargas y guarda su id_carga en una variable.
  2. ETL Principal o ETL Iteracion 1 (Data Flow Task): extrae, transforma y carga los datos.
  3. Calcular duplicados (Expression Task): duplicados = filas antes del Sort − filas después del Sort.
  4. Cerrar carga (Execute SQL Task): actualiza la ejecución con los conteos finales.

Data Flow (ETL Principal)

#ComponenteTipoFunción
1ORIGEN_CSVFlat File SourceLee dataset_consolidado.csv (UTF-8, 23 columnas).

10SORT_DuplicadosSortOrdena por id_original y fuente y elimina duplicados.

17Union All, RC_Revision, DEST_RevisionUnion All, Row Count, OLE DB DestinationReúnen las tres ramas y las guardan en revision.desaparecidos_pendientes.

La iteración 1 usa el flujo ETL Iteracion 1, que solo convierte tipos y elimina duplicados. Las iteraciones 2 y 3 usan ETL Principal. Los resultados están en Resultados de las tres iteraciones.
