Recursos para reproducir el trabajo

  • etapa6/preparar_datos_orange.py — genera los tres archivos que se abren en Orange a partir del dataset tratado
  • etapa6/datos/ — supervisado_ml_2007_2025.csv, clustering_municipios.csv y preparacion_resumen.json
  • etapa6/orange/ — flujos de Orange (supervisado.ows, clustering.ows, comentarios.ows)
  • etapa6/youtube/extraer_comentarios_youtube.py — extracción de comentarios con la YouTube Data API v3 (requiere una clave propia en .env, que no se publica)
  • etapa6/youtube/stopwords_extra.txt — palabras vacías adicionales para el preprocesamiento de texto
  • data/conocimiento_oculto.json — hallazgos que alimentan esta sección de la aplicación
